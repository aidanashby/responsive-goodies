<objective>
Pragmatic PHP 8.x modernisation: replace isset() ternaries with ?? throughout, and add
return type declarations to all non-trivial methods. Skip typed properties and match
expressions — the goal is meaningful modernisation at low risk for a personal plugin.

Scope (pragmatic subset only):
- ?? operator: replace `isset($x) ? $x : $default` with `$x ?? $default`
- Return types: add `: void`, `: bool`, `: string`, `: array`, `: false` etc. to all
  non-trivial public and private methods. Use `mixed` or omit for WordPress filter
  callbacks where the return type varies by context.
- Do NOT add typed class properties
- Do NOT convert switch to match
- Do NOT add constructor promotion
</objective>
